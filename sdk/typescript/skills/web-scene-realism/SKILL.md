# 实时场景写实优化

先从用户实际游览的距离看完整画面。选一条常走路线和一个能看清整体的机位，保存当前版本。在图上指出一个可观察的问题，例如“转过街角后，整排树冠只剩同一个圆形轮廓”。记录它在画面中的位置、占比和持续时间，据此决定改哪一批资产或哪一段渲染。

| 从画面看到的症状                         | 首个对照                                                                   | 深入处理                                                               |
| ---------------------------------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 灰、糊，前后层次弱                       | 锁定曝光、机位与分辨率，分别切换空气散射和后处理，检查近景文字、远楼与天空 | [光照与材质](references/light-and-material.md)                         |
| 背光面发黑、屋面缺反光、曲面显出三角形   | 对同一表面比较原贴图、中性漫反射与无光照贴图，再检查轮廓是否有折角         | [光照与材质](references/light-and-material.md)                         |
| 树像道具、建筑像方盒、草皮露出而草叶稀少 | 在正常视距回放 LOD 切换，按可见轮廓、覆盖面积和重复次数盘点资产            | [资产、植被与地形](references/assets-and-ground.md)                    |
| 远景草地整片同色，近处已有草皮纹理       | 用材质遮罩定位地块，把相机可见的地面网格与多日期地表反射率配准             | [地块色差与覆盖核验](references/assets-and-ground.md#远景草地整片同色) |
| 俯瞰公园发白，树冠间像蒙灰               | 分别查看航片、空气散射和透明接触阴影，用实拍核对地面相对天空的亮度         | [航片植被曝光](references/assets-and-ground.md#树冠之间的航片偏亮)     |
| 玻璃像灰卡，近水有亮带或整片远海偏亮     | 固定天气，分开查看窗面漫反射、环境倒影和水面法线，比较近岸与远岸           | [玻璃与水面](references/reflections-and-water.md)                      |
| 截图更清楚，移动时却闪烁、拖影或掉帧     | 重放同一相机轨迹与动画时钟，逐帧比较轮廓、纹理稳定性和帧耗时               | [实拍对齐与漫游验收](references/visual-verification.md)                |

用户要求整幅场景自然可信时，以正常游玩距离的第一眼观感和连续漫游作为验收标准。把步行、临水和远眺全幅画面并排，先看天空与水面的亮暗、两岸的受光是否协调，以及近景、中景和天际线能否拉开。每轮只选一个影响整幅画面或贯穿路线的问题，优先用场景级光照、环境反射、色调或成片资产调整。实拍只用于判断这些整体关系。单体的纹理与构件差异留待用户另行指定。候选在全幅正常视距下看得出改善，才进入测试版。

交付能打开的版本或本地可复现入口、同机位前后对照、运动中最明显的一处变化，以及实际测到的开销。说明仍存在的偏差和测量条件。场景的太阳角、曝光、距离阈值、采样强度与性能目标都从当前素材、观看距离和目标设备取得。
