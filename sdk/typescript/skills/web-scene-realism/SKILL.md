# 实时场景写实优化

先从用户实际游览的距离看完整画面。选一条常走路线和一个能看清整体的机位，保存当前版本。在图上指出一个可观察的问题，例如“转过街角后，整排树冠只剩同一个圆形轮廓”。记录它在画面中的位置、占比和持续时间，据此决定改哪一批资产或哪一段渲染。

| 从画面看到的症状                           | 首个对照                                                                   | 深入处理                                                |
| ------------------------------------------ | -------------------------------------------------------------------------- | ------------------------------------------------------- |
| 灰、糊，前后层次弱                         | 锁定曝光、机位与分辨率，分别切换空气散射和后处理，检查近景文字、远楼与天空 | [光照与材质](references/light-and-material.md)          |
| 背光面发黑、曲面显出三角形                 | 对同一表面比较原贴图、中性漫反射与无光照贴图，再检查轮廓是否有折角         | [光照与材质](references/light-and-material.md)          |
| 树像道具、建筑成片像方盒，岸线或路缘有跳变 | 在正常视距回放 LOD 切换，按可见轮廓、覆盖面积和重复次数盘点资产            | [资产、植被与地形](references/assets-and-ground.md)     |
| 玻璃像灰卡，水面像磨砂金属或一道道亮带     | 固定天气，分开查看窗面漫反射、环境倒影和水面法线，比较近岸与远岸           | [玻璃与水面](references/reflections-and-water.md)       |
| 截图更清楚，移动时却闪烁、拖影或掉帧       | 重放同一相机轨迹与动画时钟，逐帧比较轮廓、纹理稳定性和帧耗时               | [实拍对齐与漫游验收](references/visual-verification.md) |

每轮围绕一个能被画面对照推翻的假设做候选。优先修复会在整条路线重复出现的问题。将有效的改法推广到同材质、同来源或同一 LOD 的资产，保留每项修改与源资产的对应关系。若收益仅在差分图放大后可见，回到全景重新选题。

交付能打开的版本或本地可复现入口、同机位前后对照、运动中最明显的一处变化，以及实际测到的开销。说明仍存在的偏差和测量条件。场景的太阳角、曝光、距离阈值、采样强度与性能目标都从当前素材、观看距离和目标设备取得。
