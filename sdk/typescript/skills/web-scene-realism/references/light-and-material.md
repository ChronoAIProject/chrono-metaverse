# 光照与材质

## 分辨雾感来自哪里

保存实际运行中的显示天空、线性 HDR 辐射贴图、天空旋转、太阳方向、曝光、色调映射、输出色彩空间和绘制分辨率。核对材质和水面绑定到的纹理版本。本地测试夹具可能有同名旧天空，日照和倒影也可能各自读取不同资源。

固定机位做“原状 → 单项切换 → 恢复”的对照。对空气散射，分距离取相邻楼面和天空，记录它们的亮度差，再看全图的平均绝对像素差。对画面发糊，先对照实际像素尺寸与 CSS 尺寸，再逐项检查动态分辨率、抗锯齿、纹理 mip、斜角过滤、泛光和景深。细栏杆、路面接缝和树冠边缘适合判断损失发生在哪一层。恢复后两张基准图仍有明显差异时，先找自动曝光、动画或流式加载造成的变化。

## 对齐天空和投影

用几何明确的竖杆、檐口或楼角核对太阳方位和高度。区分地图真北、模型朝向和环境贴图旋转，检查天空中的太阳、地面投影与窗面高光能否同时对上。用线性 HDR 估计直射与天空漫射的比例；面向不同方向的中性表面可检验天光是否过于均匀。阴影边缘发虚时，根据目标视距分配阴影贴图覆盖和采样半径，观察移动镜头时的抖动。

## 区分材质和光照

| 同一表面的受控画面                       | 观察与下一步                                                                                              |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 原材质与无光照显示的原色贴图             | 若同一侧的大片阴影在两张图中都存在，检查源照片的光照是否已烘进底色。                                      |
| 中性灰漫反射，分别开启和关闭太阳直射     | 原材质发黑而中性灰受光正常，优先查底色、AO 和顶点色。中性表面也异常时，核对天光强度、太阳方向和阴影覆盖。 |
| 保留光源，只显示漫反射、镜面或间接光之一 | 查清玻璃的灰来自漫反射还是环境贴图，查清屋檐背光来自遮蔽还是阴影贴图偏差。                                |

颜色贴图按其编码解码，光照运算在线性空间进行。法线、粗糙度、金属度和 AO 按数据读取。实拍 JPEG 上的亮度比可比较视觉层次，推算材料反照率还需要曝光与照明信息。用同一张照片里的天空、混凝土或其他可辨认的参照面归一化，并注明天气差异。

## 按表面修复

- **扫描贴图的重复阴影。** 用材质槽、几何朝向和 UV 岛划出同种涂层，保护窗洞、接缝、支撑和透明通道。在岛内估计大尺度底色，保留细部相对底色的变化。将校正延伸至该岛的边缘填充区，复查 mip 缩小时的接缝。在向阳面和背光面分别比较照片，过亮的一侧也应进入选择条件。
- **曲面出现硬折线。** 轮廓平顺而面内出现三角明暗跳变时，按共享位置找到实际相邻的边，按局部连通面和二面角重算法线。保留设计折边、薄壳正反面及 UV 接缝两侧的顶点属性。选取能保留棱线的平滑范围，比较折线两侧亮度跳变和侧影。若轮廓本身呈多边形，按目标视距增加轮廓几何或调整 LOD。
- **物体漂浮或阴影过死。** 先核对底面高度、投影与接收标记、阴影相机覆盖、分辨率和偏移。对于落地面、桥底与窗槽，可在独立 UV 或顶点上估计局部天光可见度，调制间接光。用太阳移动或物体进入阴影时的画面检查接触处是否叠加变黑。
