# 批量资产、植被与地形

## 从整条路线列清单

从场景清单列出模型、纹理、实例和 LOD，记录来源、许可、尺寸单位、三角形数、贴图尺寸、重复次数和变换。用实体 ID 图、拾取或分层开关把画面里的轮廓归到资产。按路线统计屏幕覆盖与重复出现的位置，同一资产的多个实例归在一起。包围盒相交只说明可能命中，遮挡复杂时用实际可见三角面复核。

| 一批资产的共同问题           | 成批处理方式                                                                                                                     | 在哪里验收                                                         |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 道路树冠圆整、远看像实心球   | 按当地树种或可信的外形资料选树冠宽高比、主枝分叉、透空和边缘叶簇。使用有差异的树形实例，按真实株距和树池位置摆放。               | 从路口、对岸和高处看树列轮廓及天空透空率，尤其看中远景 LOD。       |
| 立面是平板或重复窗纹         | 从可辨认照片或测绘轮廓恢复层高、窗列节奏、遮阳沿与底层退界。只给在目标距离形成侧影、视差或投影的结构补几何。                     | 比较一排楼的天际线、向阳面与背光面，沿街移动看窗槽和檐口。         |
| 桥、道路、步道和岸线交界跳变 | 将实测控制点、地图要素和模型统一到同一米制坐标系，核对高程基准、朝向、桥下通行净空和岸墙接水位置。替换地图挤出时按对应要素去重。 | 沿路缘、桥面和水线连续移动，检查穿插、悬空、重影及切瓦片时的接缝。 |

树叶和细枝缩小后，检查透明裁切与 mip 是否令冠幅缩水或形成实心块。可以用保持覆盖率的 mip、具有透空的中景树冠网格、方向合适的远景树卡来做同机位比较。实例化前核对材质、投影和每株变换，按资源共用来降低绘制成本。

近处铺装和墙面按实物尺度校准纹理重复周期，让接缝、粗糙度和法线对应到同一表面。大面积草地、树冠或屋面可从多个日期的正射影像取样，用有效像元的中位数约束成片色差，并避开云、投影和混合边界。把此类远观参照与步行距离所需的几何、纹理细节分开校验。

批量换模时保留原摆放锚点，用真实尺寸校正比例和轴向。分别核对几何、UV、材质槽、法线、透明度、碰撞或可拾取范围。只改贴图时，可逐缓冲比较几何字节；只改法线时，可核对索引、位置与纹理。对来源年代不同、被遮挡或身份不确定的资产保留原版本，记录需要补哪一个视角。
