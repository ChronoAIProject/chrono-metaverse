# 第 8 章 已知限制与常见坑

按环节列出前厅各轮踩过的坑和现在的限制。处理办法后面的章节号指向详细说明。

## 8.1 现在做不到的

| 限制 | 影响 | 现在怎么办 | 以后 |
|---|---|---|---|
| 网站没有环境贴图和反射 | 镜子、镜面柜、玻璃幕墙看不到倒影和外景；粗糙度低于 0.5 的面发暗、出亮斑；金属发黑 | 镜面用钢灰色、玻璃用颜色 + 透明度示意；粗糙度 ≥ 0.5；金属用颜色（6.11） | 加环境贴图 |
| 网站画形状时不用贴图的透明通道 | 独立的贴花层（透明的 LOGO 叠在墙前）做不了 | 字样整面保留在贴图里，或合成进底材贴图（6.6） | 支持透明贴图后做贴花层 |
| 着色方式、法线、粗糙度要网站按 SHAPES 画 | 网站还不支持时，`albedo` 贴图按扫描烘焙的看法画（偏平、偏暗），法线粗糙度不起作用 | 以网站当前实现为准，上线前在预览里看 | 设计第 12 节 |
| 重建包第一版没有方块 | 重建层不能写方块化的结果 | `voxelize` 只作本地实验 | 清单版本 2 |
| 扩展层不能"隐藏或替换"重建层的某件物体 | 重新布置桌椅只能重建或等以后 | 发布新的重建包 | `hides`，另行设计 |
| 带骨骼的模型只取绑定姿态 | 找不到坐姿、靠姿的人形机器人 | 换站姿的库模型，或保留手写（4.2、4.3） | — |
| 外部模型只能有一个整体 `tint` | 椅身和椅脚不能分别调色 | 挑部件深浅关系对的候选（4.5） | — |
| 工作台的贴图命令、穿插检查还没实现 | 要按 6.12、4.6 节的方法自己写脚本 | 同左 | 进工作台 |
| NyxID 服务还没注册 | `/api/v1` 一律 401，命令行写不了；只有部署种子能写 | 用 `pull --share` 读公开快照；演示空间走种子（7.5） | 注册后命令行直接推送 |
| `metaverse-rebuilder` 角色还没建 | 通过接口谁都写不了重建层 | 同上 | 平台管理员建角色 |

## 8.2 采集

| 坑 | 处理 |
|---|---|
| 玻璃、镜子后面扫出一大片"东西" | 是倒影虚像，不建；玻璃面按竖梃、窗台推断（3.5、3.7） |
| 深色屏幕扫成一团黑 | 拍照片，按照片选库模型（2.3） |
| 贴墙家具背面没扫到 | 朝向以高度图为准（4.4）；能绕到背后的扫描时绕一圈 |
| 两趟拼起来留下接缝、长墙漂移 | 一趟扫完、回到起点（2.3）；建模时长墙只拟合一个平面 |
| 只留了处理后的网格 | 打开 Scaniverse 的"保存原始数据"，另拍照片和视频（2.4） |

## 8.3 对齐、基线和结构

| 坑 | 处理 |
|---|---|
| 已有空间重新自动对齐，整层和锚点、扩展层错开 | 一律用线上的变换（`scan/transform.json`），不重新对齐（3.2） |
| 在旧坐标系里写的物件直接拿来用 | `metaverse-recon reframe` 换算，不要手工平移 |
| 截短墙面贴图面板后贴图挪位 | 组里放 2 毫米的定位小块，保持投影范围（3.5） |
| 把倒影、地面起伏、桌下拉丝当成漏建的物体 | 按 3.7 节的表判断，判断写进记录 |
| 结构贴图在服务端重算后哈希对不上（以前的问题） | 本地打包时贴图文件随包上传、按哈希引用，已经不会发生（3.6） |

## 8.4 建模

| 坑 | 处理 |
|---|---|
| 挑模型时看原文件，导入后贴图成噪点、平铺贴图出划痕、动作模型成 T 字 | 先 `models` 导出，按导出后的样子挑（4.3） |
| 19 万面的模型减到 10 万后塌成多面体 | 挑 10 万面以内的，或大面平滑的软包才接受减面（4.2） |
| 模型自己的正面不是 +Z，自动摆放侧着放 | 看俯视图，`--yaw` 限定重摆（4.4） |
| 把对的朝向"纠正"反了 | 以高度图和俯视图为准，不只看"正面"图（4.4） |
| 浅色实物配了深色模型，`tint` 调不亮 | `tint` 只能调暗、调色相：浅色实物选同样浅或更浅的候选（4.2、4.5） |
| 同一个 tint，纯色模型显得更亮 | 纯色材质的 tint 乘在线性底色上，按显示出来的颜色换算（4.5） |
| 悬空 2–6 厘米、穿进窗台、伸进桌脚 | 合并后统一查穿插和落地（4.6） |
| 8 把同款椅子偏航各不同，导出 8 个文件、18 MB | 同一排统一偏航；手写的同款做模板（4.4） |
| 手写一切都是直角盒子 | 圆角、弧形轮廓、扫掠、放样、凸包（4.7） |
| 追着扫描噪声贴 | 偏差到 2–3 厘米以后不再追（4.7） |
| 手改 `props.source` 或 `model` | 只能来自 `fetch` / `place`；署名是写入方的声明，责任在自己（4.9） |
| 用了 NC、ND、SA 许可的模型 | `search` 已过滤；Sketchfab 不在 Objaverse 镜像里的模型打包时用不了（4.2） |

## 8.5 贴图

| 坑 | 处理 |
|---|---|
| 去光照时色度拉平把白色点阵染黄 | 有独有图案的面只调亮度（6.3） |
| 去过光照的贴图仍按 `baked` 写，网站上发灰发平 | 写 `albedo`，再标定颜色（6.1、6.10） |
| 只在一个机位标定，换个角度颜色偏 | 人眼和近景多个机位一起标定，另用样本外机位检查（6.10） |
| 用错相机灯光判断颜色（工作台渲染页以前没乘 π，暗约四成） | 现在已经和网站对齐；判断颜色一律用网站的灯光（5.5） |
| 粗糙度写 0.3，网站上发黑、出亮斑 | 粗糙度 ≥ 0.5（6.11） |
| 平铺看得出网格状的重复 | 加大周期、压掉显眼的大纹路，拼 3 × 3 检查（6.8） |
| 法线强度太大像塑料浮雕 | 石材、木饰面 0.2–0.35（6.9、6.11） |
| 用 AI 生图生成 LOGO、字样 | 不用；独有内容从扫描取（6.7.1） |
| 用了不可商用的生图模型（FLUX.1 [dev] 等） | 只用 6.7.2 节表里允许的；换模型记下许可 |
| 把带人、屏幕、白板的照片发给外部生图服务 | 只发裁剪到材质的图，按公司数据政策（6.7.4） |
| 法线贴图是 DirectX 约定，凹凸反了 | 绿色通道反过来（6.9） |
| 贴图超过 4096、模型里的贴图超过 2048 | 打包时会被拒或被缩小；生成时就按上限（6.12） |

## 8.6 打包、推送、发布

| 坑 | 处理 |
|---|---|
| 手改了 `out/bundle/` 里的文件，检查不过 | 改物件集、重新打包（7.1） |
| 清单没有 `base` | 用工作区打包（`bundle` 自动写）；确实要基于最新版本时 `--base latest`，冲突检查只覆盖从现在起的变化（7.2） |
| 403 `rebuild_permission_required` | 令牌没有 `metaverse:rebuild:write`：请平台管理员分 `metaverse-rebuilder` 角色（7.4） |
| 推送说某个文件"本地没有，空间里也没有可以复用的" | 通常是原始扫描：`metaverse pull --scan`（7.2） |
| 发布 409，键 `layer:rebuilt` | 中途有人改过重建层：看清楚再 `--replay`，或重新拉取、重新打包（7.3） |
| 锚点被跳过 | 编号已存在或曾经存在；可能被别人占了，请人判断（7.2） |
| 锚点漂移 | 重建包不改已有锚点：用实体区草稿挪（7.2） |
| 包里的锚点不能删 | 用实体区草稿另外删（7.7） |
| 清单里每条记录不超过 64 KiB | 记录不要缩进（工具写出时就是紧凑的）；过大的形状拆成模板 |
| 种子包里带了内部级锚点、建模记录 | 种子一律 `bundle --seed`，`bundle check --seed` 会警告（7.5） |
| 发布页刚上传的文件下载 404，种子失败 | 下载类失败下次启动自动重新排队，修好后重启即可（7.5） |

## 8.7 网站显示

| 坑 | 处理 |
|---|---|
| 加载量太大（精致模型版估计约 48 MB） | 统一偏航去重导出；选三角形少、贴图小的模型；手写同款做模板 |
| 模型实际比记录的 `bounds` 大 | 服务端按顶点数据实测包围盒，要求与记录一致；网站另有兜底，把模型缩进 `bounds`（设计第 9 节） |
| 默认剖切切掉了想看的东西 | 剖切高度按扫描的天花板算；用户拖滑块后按用户的 |
