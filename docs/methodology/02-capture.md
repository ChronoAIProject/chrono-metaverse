# 第 2 章 采集

扫描决定了后面所有步骤的上限：结构的位置、物件的尺寸、贴图的清晰度都从扫描来。扫描里缺的东西（贴墙家具的
背面、被挡住的角落、玻璃后面）后面只能推断。这一章讲怎么扫、要留下什么。

外部事实（Scaniverse 的功能、导出格式）查证于 2026-11-10，来源列在本章末尾。

## 2.1 设备和应用

- **设备**：带激光雷达的 iPhone Pro 或 iPad Pro。前厅用的是 Scaniverse 的网格扫描，约 34 万个三角形、8192² 的贴图。
- **应用**：Scaniverse。它有网格（mesh）和高斯泼溅（splat）两种结果；官方建议在几何精度、尺寸要准的场合用网格，
  追求观感时用泼溅。本项目的流程要网格（glb、drc、obj），**选网格**。
- **处理模式**：Scaniverse 1.7.0 起有"细节模式"（Detail Mode），在处理菜单里选，按摄影测量出更细的几何和贴图；
  适合小物件，整间房的扫描用默认处理即可，需要时用保留的原始数据重新处理（2.4 节）。

## 2.2 扫之前

- **灯全开、光照均匀**：官方建议在明亮、均匀的光照下扫，避开强阴影、直射阳光和变化的光。贴图里烤进去的阴影和
  高光在第 6 章要一块块清掉，现场多开一盏灯省很多事。
- **清场**：人和移动的东西不要出现在画面中央（官方建议）。临时杂物（外卖袋、快递盒）想不想留在孪生里，扫之前定；
  前厅留下了桌上的袋子、文件夹，后来都要逐件建模。
- **门的状态**：门开着扫和关着扫是两种结构；按"平时的样子"定，扫的时候不要中途开关。
- **量几个参考尺寸**：用卷尺量两三个长距离（一面墙的长度、桌子的长宽、门洞的宽），记下来。以后核对扫描比例和
  对齐时用得上。
- **记下难扫的表面**：玻璃幕墙、镜子、镜面柜、深色屏幕、反光地面。官方建议尽量少扫镜子、玻璃这类反光和透明的
  表面；做不到（前厅一整面南墙是玻璃）就记下来，建模时这些地方要按框架、交线推断（第 3.5 节）。

## 2.3 怎么扫

- **匀速连续地移动**：官方建议设备稳定、连续地移动，哪怕很慢；不要突然转向；和之前拍过的地方保持重叠。光线暗的
  地方更慢。
- **一趟扫完、回到起点**：前厅入口那面木墙是两趟拼起来的，扫描面在 x≈3.10 和 3.03 两处，中间留下一条接缝；西侧
  12 米长的木墙因为漂移斜了 0.77°（第 3.5 节）。长墙要沿着走完、最后回到起点闭合。
- **换高度、换角度**：先齐腰高绕一圈，再举高、蹲低各补一圈；桌面、台面要从上往下扫到。
- **天花板也扫**：网站的剖切默认高度按扫描里天花板的高度算（[整体设计](../ARCHITECTURE.md) 7.1）。
- **能绕到背后的家具绕一圈**：贴墙的家具背面扫不到，从背后看扫描反而像正面（能看到坐垫和靠垫的里侧），建模时
  朝向容易弄反（第 4.4 节）。离墙有空的沙发、柜子，把背后也扫到。
- **深色屏幕扫不出形状**：前厅的两台显示器在扫描里各是一团黑，最后按常见显示器的样子用了库里的模型，偏差 3–6 厘米。
  这类东西多拍几张照片，建模时对照。
- **地面的材质分界**（地毯和石材、门槛条）要扫清楚：贴图做分区时按扫描找直线边界（第 6.6 节）。

## 2.4 保留原始数据，留给以后更精细的重建

一份网格扫描只是一次处理的结果。以后要更清楚的贴图（用原始照片重新投影）、更准的几何（深度补全、重新融合），
都要原始的照片、深度和相机位置。所以**每次采集都留三样东西**：

1. **Scaniverse 的原始数据**：处理完以后（或在设置里）打开"保存原始数据"（Save Raw Data）。原始数据里有相机的彩色帧、
   激光雷达深度和设备轨迹，平时处理完就删掉以省空间；保留以后可以在应用里"重新处理"（Reprocess），换细节模式或别的
   设置。官方资料只说明在应用内重新处理，没有说明能把这些帧导出成文件——所以它只是保底，不能代替下面两样。
2. **照片**：每类材质（台面、地砖、木饰面、皮革、地毯、印刷品）正对拍几张清楚的近景，相机离表面 0.5–1 米；同一位置
   再拍一张带参照物（卷尺、A4 纸）的。保留原图和拍摄信息，不要用聊天工具转发压缩过的。第 6 章做贴图时，照片是
   AI 生图和颜色核对的参考。
3. **视频**：手机相机绕房间慢慢走一圈，4K、30 帧，镜头平稳。以后可以从视频抽帧做摄影测量，也方便评审时对照现场。

要更完整的原始数据（每一帧的彩色、深度和相机位置都能导出），可以另用能导出原始帧的应用再扫一次：Polycam 的原始数据
导出是一个 zip，`images` 目录里是原始照片；开源的 Stray Scanner 导出视频、深度、置信度和位姿（许可和用法见
[开源方案调研](../research/scan-to-model.md) 第一节第 1 条）。这些格式本项目现在还不读，留作以后的精细重建。

**存放**：原始扫描、原始数据、照片、视频都放在团队的存储里，记下文件名和 sha256；**不进任何 git 仓库**。照片里可能有
人、屏幕内容、白板，给外部服务（第 6 章的生图接口）之前要裁剪到只剩材质。

## 2.5 导出和交给本地工具

- **格式**：Scaniverse 的网格可以导出 OBJ、FBX、GLB、USDZ 等（不同资料列的格式略有出入，以应用里的菜单为准）。本地
  工具和服务端认的扫描格式是 glb、drc、obj，或者装着**正好一个**网格成员（glb、drc、obj）加贴图（jpg、png、mtl）的
  zip（[SHAPES](../SHAPES.md) 第 8 节）。
- **前厅的扫描**：用的是 Scaniverse 分享页上的两个文件 `mesh.drc`（Draco 压缩网格，1.0 MB）和 `tex.jpg`（8192² 贴图，
  4.9 MB）。`metaverse-recon scan-zip` 按固定规则（存储不压缩、成员按顺序、时间固定）把它们打成 zip，同样的成员永远得到
  同样的哈希，所以种子从 Scaniverse 原地址下载、打包后，哈希和线上已有的扫描相同，不用重新托管（第 7.5 节）。
- **上限**：扫描 ≤ 1 GiB（`limits.json`）。扫描经重建路径上传，**不公开**，预览链接也拿不到。
- Scaniverse 贴图的坐标原点在左上角（第 0 阶段实测），本地工具已经处理。

## 2.6 前厅这次扫描暴露的问题（以后扫的时候注意）

| 现象 | 原因 | 后面怎么处理 |
|---|---|---|
| 玻璃幕墙后面 15–75 厘米有大片"东西" | 玻璃的倒影被当成表面（虚像） | 不建；玻璃面按竖梃、窗台推断（第 3.5、3.7 节） |
| 展示柜镜面里有一整间会议室 | 镜子的虚像 | 不建；柜体按外框建 |
| 两台显示器各是一团黑 | 深色屏幕扫不出有效的形状 | 用库里的显示器模型按位置摆放，偏差 3–6 厘米 |
| 沙发、休闲椅背后是空的 | 贴墙，背面扫不到 | 朝向以高度图为准（第 4.4 节） |
| 入口木墙一条竖向接缝 | 分两趟扫 | 不改结构，按其中一面建 |
| 12 米长的木墙斜了 0.77° | 扫描漂移 | 按斜平面拟合（残差 1.7 厘米），不追逐局部 3–4 厘米的起伏 |
| 前台背后地面比结构高 4–8 厘米 | 地面起伏或扫描误差 | 不建成物体 |
| 会议桌下一片拉丝碎片 | 桌下光线暗、视角少 | 不建 |

## 2.7 采集检查清单

- [ ] 灯全开、关掉会动的屏保；人离开画面中央
- [ ] 门、窗帘、椅子摆成"平时的样子"
- [ ] 量了两三个参考尺寸
- [ ] 一趟扫完、回到起点；天花板、台面、家具背后都扫了
- [ ] Scaniverse 选网格；处理完打开"保存原始数据"
- [ ] 每类材质的近景照片（带一张参照物）、绕场一圈的视频
- [ ] 导出网格（glb / obj，或分享页的 drc + jpg），连同照片、视频放进团队存储，记下 sha256
