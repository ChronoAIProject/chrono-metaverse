# 工作台 NyxBot

进入 `/workspace`，选择已有空间，点「空间助手」，选择「NyxBot · 对话编辑」。聊天窗内嵌 `@chronoai/nyx-assistant-sdk/widget`，通过 SDK 的独立 chrono-cd 服务调用 NyxID 的 `llm-nyx` 和 `nyxagent/chat`。工作台的扫描与模型导入继续使用 CMA。

## 连接与恢复

点击「连接 NyxID」，在 NyxID 授权页核对设备码，选择当前登录账号的个人 Agent Key。需要 `proxy` 权限和 `llm-nyx`、`chrono-metaverse`、`chrono-llm-public` 三个服务。NyxID 决定 Key 可访问的空间、操作和数据。SDK 通过 Web Crypto 加密浏览器子凭据；已有工作台 NyxBot 凭据会在本机加密并向 NyxID 核验，核验成功后移除原存储。断开授权撤销当前子凭据。

聊天按标签页、工作区和已核验子凭据保留最近 30 条消息。网络中断后点击「核对原请求」。刷新后的挂件通过已知响应编号读取原结果；旧窗口的页面动作由用户核对。迁移前的聊天可在「查看迁移前的对话」展开，旧请求编号可用于核对已执行的空间修改。

## 操作空间与查看器

点击示例只填写消息。助手先读取编辑指南和空间实际状态，在草稿上修改并生成预览。点击「查看草稿预览」检查效果；「发布这个草稿…」需要确认具体预览才会发送发布指令。确认后的实际发布仍由 NyxID 和空间服务核验权限。

点选物件后说“读取并聚焦当前选中物件”，SDK 会把真实选区和聚焦结果送回原会话。用户还可以切换空间、组合、草稿、显示模式、样式、剖切高度或镜头。涉及离开工作区的操作在原会话收到工具回执和最终答复后导航。

NyxID 自定义服务使用字面空间路径规则时，模板 OpenAPI 工具可能被过滤。可将该用户连接的规范地址配置为 `/api/openapi.json?spaceId=<空间编号>`：它保留 operationId，但把空间路径固定为该编号并去掉可变的 `space_id` 参数，供 NyxID 正常发现工具。随后给 Key 配置相同字面空间路径的 allow 规则，例如 `POST:/api/v1/spaces/chronoai-lobby/rebuild/drafts/{draft_id}/moves`。**规范地址只控制工具发现，真正的访问限制由 Key 的操作规则和服务端权限共同执行**；单独更换规范地址不构成隔离。该连接的工具发现将只显示这一空间；需编辑其他空间时应另设连接或重新明确配置范围。目录服务已有稳定 endpoint ID 时，优先使用 NyxID endpoint 输入约束固定 `space_id`。

工作台的已发布空间和本站草稿预览共用同一个 WebGL 查看器；切换草稿修订、返回已发布版本或切换可访问空间时，已解析的相同内容哈希模型、几何与贴图继续复用。新内容按需加载，每次打开草稿仍重新校验预览权限和有效期。注销或更换登录账号会释放查看器；不跨账号共用私有缓存。独立打开分享页/预览页、刷新整个网页和首次进入不同模型仍可能加载资源。
