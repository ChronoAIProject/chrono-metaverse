# 空间聊天工作台

用户打开已有空间后持续聊天，编辑由在线 CMA worker 执行。网页提供空间发现、三维查看、对话、进度、草稿验收和明确发布；不提供人工坐标、方块或 JSON 编辑器。

## 网页流程

1. 连接 NyxID 后，自动列出当前账号的个人空间和所属组织空间；显示组织、只读/可调整状态，支持筛选和继续加载。即使尚未同意 CMA，也可查看自己的空间。
2. 选择空间，右侧直接加载当前已发布版本；私有/凭链接查看的空间无需另行生成分享令牌。查看器沿用时间轴和实时 head 更新。
3. 明确启用 CMA 后，在聊天框描述变化。首次发送创建在线 worker，后续消息复用它和当前草稿。Enter 发送，Shift + Enter 换行，输入法选字不发送。
4. 网页每 2 秒串行观察准备任务、对话及当前 Responses v2 输出，显示已经产生的回复和工具执行状态。每轮可见修改后要求 worker 生成新预览，网页自动跟随最新链接；这不是逐 token 流式渲染，也不保证每个底层编辑操作立即生成场景。
5. 查看新草稿后明确要求发布；确认绑定正在显示的预览，切换到新预览必须重新确认。发布指令包含真实空间、草稿编号、rev 和 baseSeq，版本冲突不自动覆盖。
6. 按空间保留此标签页的 worker、未发送消息和请求恢复记录；切换空间不复用另一空间的任务。网络失败后只允许用户明确重试原请求；不自动重试写操作。手机提供“空间 / 聊天 / 预览”切换。
7. 按编号打开、新建空间和接入已有 worker 位于次要入口。模型、执行审批、服务授权和完整环境控制仍可在 CMA 官方界面处理。关闭网页或授权不等于停止已受理任务。

## 授权与调用

```text
浏览器 ── HttpOnly 会话 + CSRF ──> metaverse 网页后端
  │                                    ├─ 已核验用户 + 实时组织权限
  │                                    │      ├─ 列出个人/组织空间
  │                                    │      └─ 只读空间查看器投影
  │                                    │
  └─ 明确启用 CMA 后提交聊天 ────────────┴─ 同用户 OAuth → 固定 CMA API
                                                              │
                                           CMA 托管的服务范围 Agent Key
                                                              │
                                                  NyxID → metaverse API
                                                              │
                                                      资源 ACL / 操作权限
```

不扩大既有 `openid offline_access` scopes，不向浏览器或 worker 提供用户 OAuth 凭据。空间发现/查看和 CMA 调用分别验证当前用户与会话；CMA 还要求当前浏览器的明确同意版本。已有业务 `/api/v1/*` 仍只接受 NyxID 签名身份。

新增浏览器只读接口：`POST /api/auth/nyxid/spaces`（每页 40 条、按编号分页）；`POST /api/auth/nyxid/view/spaces/{id}` 及固定的 `head`、`snapshot`、`timeline`、`events`、`events/density`、`state` 子路径。只读中间件复用资源 ACL，校验组织归属证据；场景沿用公开查看器投影，内部锚点不随之暴露。不签发分享令牌，不更改可见性，所有响应不缓存，结束前再次核对 OAuth 授权版本。已发布的内容寻址区块/资源沿用原公开读取规则。组织列表或权限服务故障显示读取失败。

新 worker 仅申请 metaverse 业务服务，加上 CMA 必需模型/技能基线。组织编号只选择目标，不代表授权。新建聊天使用显式 `context.chat:true` 的交互约定，旧恢复请求保持原格式，避免改变同一幂等键的上游请求。先草稿后发布是任务约定；硬性禁止发布仍须 NyxID 的操作权限。复用已有 worker 不更改其服务权限。

## 验证与限制

- 覆盖个人/组织发现、分页、无归属证据和删除中的空间、角色移除、CSRF、userinfo 故障及断开期间的读取围栏。
- 覆盖连续追问复用 worker、新预览自动显示和重新确认、空间间记录隔离、明确同意、断网恢复及安全文本渲染。
- 桌面/手机浏览器检查已有空间查看器、聊天和预览；构建后按镜像摘要部署。
- 自动观察最多 120 次，终态或错误后暂停，可手动刷新；读取权限每次请求重新核验。聊天与查看器会产生相应的 NyxID/CMA 读请求，没有后台自动写入循环。
- 首次用户 OAuth 同意、CMA 的可续期环境授权及真实 worker 修改结果需用户授权后在线验收，不能由模拟测试替代。
