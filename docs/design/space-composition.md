# 空间原生组合与查看菜单

目标：一个空间同时拥有自身内容和子空间引用。组合不再单独存储，也不再拥有另一条修订序列。测试部署目标是 `dev` 对应的 `staging`（`chrono-metaverse`）。

## 数据与历史

- `spaces` 的 `members`、`links` 是最新组合状态的缓存；邀请仍须由被引用空间的管理者接受。
- 组合变化作为普通空间提交的 `composition` 保存完整状态，快照与关键帧保留它，和模型编辑共用 `head.seq`。
- 旧组合迁入 `spaces`，旧修订迁入 `commits`；旧接口和 `/u/` 链接作为兼容入口，新入口统一为 `/s/`。
- 子空间允许嵌套；写入时检查循环、深度和展开数量，并用事务版本栅栏防止并发构造循环。
- 实例路径标识一次摆放；局部坐标逐级旋转和平移。所有层级默认读取同一个时刻。
- 分享授权沿实例路径逐级检查，成员期取每一层授权的交集；退出后仅能回看授权期间内容。

## 菜单

- 主栏只保留空间名称、视图选择和“显示设置”。
- 显示设置中分组放置空间样式、方块画法、剖切、主题及组合排布。
- 空间导览与子空间管理进入单独的“空间”面板，时间播放操作保留在底部时间轴。
- 工作台将选择空间、创建、预览入口归并到空间菜单，避免多个相近含义的菜单并排。
- 面板支持关闭按钮、点击外部关闭、Escape 关闭并归还焦点；移动端限制面板高度并允许滚动。
