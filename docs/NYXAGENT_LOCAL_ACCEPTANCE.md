# 空间聊天流程与本地验收

验收日期：2026-11-13。范围：本地页面流程、NyxAgent 刷新恢复，以及现有功能的系统检查。本轮尚未部署测试站。

## 页面流程

工作台统一为一个“空间助手”入口，记住当前选择的 CMA 或 NyxAgent。扫描与导入继续使用 CMA；已有空间的对话编辑可使用 NyxAgent。

- 已连接的 NyxAgent 授权折叠为一行，展开后可以查看范围归属和断开授权。
- 空白对话提供任务示例；点击只填写输入框并聚焦，不自动发送。
- 执行时显示进度。“停止等待”说明任务仍在后台执行。
- 刷新后自动打开有待处理请求的对话，包括组织空间。有响应编号时自动查询原结果；没有编号时由用户显式恢复完全相同的请求。更换授权不能重放旧请求。
- 草稿结果提供预览和发布入口。发布先显示确认；确认后才发送绑定该预览的指令，取消确认不发送。发布权限、草稿修订和冲突处理仍由实际服务校验。
- 连接中断时只提供一个继续动作，请求编号和底层错误放在诊断详情。无法续聊的失败会话保留核对状态，引导确认后开始新对话。

后端独立读取已授权的上游执行，不因网页断开而取消原执行；持续校验登录权限和输出限制。服务器重启或上游异常仍可能需要核对结果，不承诺恢复已经失效的上游会话。

后端全量主命令最初在跨语言向量生成一致性检查失败：三角函数在不同平台产生末位浮点差异。该反例只检查点数上限，改用确定的整数坐标并补跑 core 全量和 SDK 向量测试。没有将原失败记录改写为成功。

压力测试还发现每次放置物件都扫描全部物件收集模板，批量导入时产生二次复杂度。改为按引用编号读取同层模板，并覆盖新模板自引用、替换后循环引用、失败不修改原状态。修复后压力场景完成 3 个任务，4 个并发分片全部返回 200。原有慢任务已停止，其独立测试库已清理。

## 真实 NyxAgent 聊天

使用真实本地 NyxID、NyxAgent、LLM、API 和 Chromium，覆盖以下流程：

1. 批准专用 Agent Key 并交付浏览器子凭据；读取当前空间及物件，下一轮正确回忆上一轮口令。
2. 将 `rb.robot` 沿 x 正方向移动 0.25 米，生成唯一一份重建草稿和预览，保持未发布。
3. 执行中真实刷新。保留原请求和会话，有响应编号的恢复只读取原结果，没有新增消息写入。第一次还遇到开发热更新造成的观察中断，手动查询成功；随后在代码稳定时再次执行刷新，页面自动等到结果。
4. 独立接口比较预览与原快照：仅 `rb.robot` 改变，只有 bounds 平移，其余物件、模型、旋转、材质、来源保持一致；已发布快照完全一致，仍为 seq 3。
5. 浏览器打开独立及内嵌预览，模型实际加载成功。检查 1680px 桌面与 390px 手机的空白对话和聊天记录，没有横向溢出。
6. 使用同一子凭据访问未授权的发布、重建包、其他空间和管理接口，全部返回 403。
7. 通过实际聊天取消草稿，旧预览返回 404，已发布快照完全一致。刷新后会话和聊天记录保留。
8. 在网页断开浏览器授权，子凭据访问返回 401；撤销本轮临时父 Key，并删除本轮临时凭据文件。原有线上授权未改变。

本机证据目录为 `/tmp/winter-summit-full-acceptance/`。`local-chat/` 保存浏览器记录、截图、精确修改比较、取消和撤销结果；完整九步报告在 `infra/dev/.run/e2e-db0679c7/report.md`。凭链接访问的测试预览已取消，凭据和预览令牌不提交仓库。

## 验收边界

- 本地 CMA 的 `workerAvailable` 为 false。CMA 授权、创建、附件、恢复、确认发布等网页流程经过夹具 E2E 和集成测试；真实扫描重建与发布经过本地工具链验收，不能将其记为真实 CMA worker 聊天通过。
- NyxAgent 的真实诊断 Key 仅允许目标空间读取、移动、预览和取消，没有发布权限。真实聊天验证发布拒绝；发布成功、版本冲突与确认约束由 API 集成、CLI 和网页测试覆盖。
- macOS 没有压力脚本读取的 Linux `/proc` 内存指标，输出的 0 MiB 无效。本轮仅确认压力场景完成，不将其作为内存预算或生产性能结论。
- 所有测试写入均使用本地 MongoDB 27027。测试端口探测曾误用默认 27018 执行只读 hello，随后修复测试脚本并显式重跑 27027；没有在该端口写入或删除数据。
- 用户报告的两笔线上结果未知请求未重放；具体请求编号仅留在本地验收记录。
