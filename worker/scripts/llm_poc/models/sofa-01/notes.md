# sofa-01 米色皮沙发：手写参数化模型说明

## 看到了什么

- 一张**双人位皮沙发**（米色/焦糖色皮面），正面朝 −Z（SHAPES yaw = 180），靠背贴着 +Z 一侧。
- 部件：左右两只**枕式扶手**（同款、镜像对称）、一整块**长条坐垫**（坐垫顶面在扫描几何里中间没有缝，按一整块建）、
  坐垫下的**底座**、两块**后仰的靠背垫**（贴图上中间有明显的缝）、靠背垫后面全宽的**靠背框**、四条**短腿**
  （正面图里左扶手下方 y 0.1–0.25 是空的、能看穿，说明主体是架空的）。
- 设计意图：
  - 扶手截面上沿是圆的：外上角圆角小（约 4 厘米），内上角圆角大（约 9 厘米），扶手前脸上缘也是圆的（约 5 厘米）；
  - 坐垫前上沿圆角约 5–6 厘米，前脸几乎竖直；
  - 靠背垫向后仰约 25°（前脸从座面 (z −0.12, y 0.40) 斜上到 (z −0.25, y 0.68)，局部坐标），顶上是圆弧，
    两端圆滑地落到扶手顶上，中间一道缝；
  - 靠背框两端在扶手后方露出，顶角圆滑。
- 扫描的问题（建模时没有追）：
  - 右半边坐着/躺着一个**移动的人（鬼影）**，x 1.85–2.3 一带是人的身体和腿；
  - **右扶手**被人挡住、重建坏了：扫描里只剩外侧一层薄壁（x≈1.56–1.62，顶到 0.72），座面一直延伸到 x≈1.65。
    左扶手是完整的（宽 0.24、顶 0.68）。按常见沙发的对称结构，右扶手按左扶手镜像建；
  - 背面几乎没扫到；扶手内部、座下有散乱碎面；左前角外面有一件木头家具、地上有杂物（不属于沙发）。

## 结构（model.json）

`group`（transform：position [2.4725, 0.084, 14.67]，yaw 180）下分 4 组：

1. 腿 ×4：`cylinder`（带 `radiusTop`，上粗下细）。
2. 扶手 ×2：`extrude`，横截面轮廓 (x, y) 带 4 个圆角（内上 0.09、外上 0.04、下角 0.015），`pitch −90` 沿 −z 拉伸 0.87，
   拉伸 `fillet 0.05` 把前脸和后端的边倒圆。左右是镜像轮廓。
3. 座：底座 `box`（fillet 0.02）+ 坐垫 `box`（fillet 0.055）。
4. 靠背：靠背框 `extrude`（侧面轮廓，`roll 90` 沿 x 拉伸全宽，顶角圆角 0.06）+ 靠背垫 ×2 `extrude`（同一侧面轮廓，后仰，
   前上圆角 0.09、后上 0.05，两端 fillet 0.08）。

同款部件（两只扶手、两块靠背垫）用同一组参数生成，扶手是镜像轮廓、靠背垫是同一轮廓平移；没有拆成空间级模板，
因为它们只在这一张沙发里出现。全部数值是看图和 `measure` 量出后手填的常数（生成脚本
`work/gen.py` 只负责排版 JSON、检查轮廓方向、算包围盒，没有调用任何拟合函数）。

## 每轮改了什么（扫描→模型：均值 / P90 / 3 厘米内，单位厘米）

| 轮 | 改动 | 新模型 | 现有算法 |
|---|---|---|---|
| 第 1 轮 | 初稿：腿 + 双扶手 + 底座 + 整块坐垫 + 靠背框 + 两块后仰靠背垫，底面 0.17 | 3.03 / 8.09 / 68.7% | 4.07 / 8.87 / 47.1% |
| 第 2 轮 | 漏建块里最大一块是座下 y 0.08–0.2 的暗面 → 主体底面压到 0.15；底座前脸 0.45→0.46、坐垫前脸 0.465→0.47（与扫描座前脸齐）；颜色调暖 | 2.90 / 7.61 / 68.4% | 同上 |
| 第 3 轮 | 用局部坐标再切左扶手：外侧 −0.875、顶 0.605、前脸 0.41；x=−0.7 处靠背仍在 → 靠背垫外端伸到 ±0.70、两端圆角 0.08（两端圆滑落到扶手上，中缝也成了圆槽）；靠背框顶 0.725、半宽 0.875 | **2.83 / 7.32 / 69.5%**（1 厘米内 32.6%） | 同上 |

模型→扫描：新模型 11.72 / 28.86 / 26.1%，现有算法 13.55 / 36.32 / 23.4%（两者都因背面、底面没扫到而偏大）。

剩下离模型 >5 厘米的扫描块基本都不是沙发本身：座下暗面（424 点）、人的身体（355 点）、右扶手位置的座面（248 点，
扫描坏了，见上）、沙发前地上的杂物（174 点）、左扶手内部碎面（138 点）。
