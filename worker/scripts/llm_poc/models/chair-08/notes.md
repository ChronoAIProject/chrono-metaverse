# chair-08 会议椅：模板 + 实例的手工建模说明

用时：约 24 分钟（09:02 开始，09:26 交付）。共对比 3 轮。

## 看到的物体

- **它是什么**：长会议桌南侧的一把桶形扶手会议椅。椅子推进了桌下，正面朝 −Z，yaw 正好是 180°。
  左右两只后脚落地点一样，都在 z≈12.02，所以没有转角。
  同排还有 chair-07、09、10，对面一排是 chair-02、03、05，外形都一样。
- **底座**：**四条腿，不是转椅底座**。扫描网格里几乎没有腿：0.30–0.48 米高度上一个点都没有。
  能判断出四条腿，靠的是两处证据：
  - 地面贴图上烘焙进去的腿影（`views --cut 0.45 --only top`）：每把椅子后面各有两个深色脚点，左右相距 0.41 米，中间没有立柱；
  - 南斜视角的整排图上，椅腿呈"/\"状向外撇。
- **靠背**：**桶形，不是平板**。俯视是 U 形：后部是一段半圆，两侧直线扶手一直延伸到前沿。
  - 外壳上沿后高前低：正后方 0.835 米（世界坐标），两侧扶手往前一路降下去，到前沿时与坐垫前沿平齐。
  - 内侧有一块后仰约 40° 的厚靠背软垫：在坐垫高度厚约 17 厘米，往上越来越薄，到顶只剩 2–3 厘米。
  - 外壳外表面上宽下窄，略呈碗形，底部向内收。
- **颜色**：
  - 外壳外侧为深棕色皮面，扫描中位色 [31,25,21]，处在阴影里；
  - 内衬、软垫和顶沿为蓝灰色布面，靠背内面中位色 [98,111,124]；
  - 腿为黑色。
- **扫描质量**：只有外壳、靠背内面和坐面扫到了。腿和座底都缺失。
  包围盒里还混有其他东西：
  - 会议桌桌面（y≈0.84），约占点数的 27%；
  - 桌沿；
  - 左右邻椅 chair-07 和 chair-09 的壳边。

## 部件（模板 `tpl-meeting-chair`，局部 +z = 正面，原点 = 地面上靠背圆弧圆心附近）

| 部件 | 形状 | 关键尺寸（局部，米） |

| 外壳（棕） | `loft`，8 层 U/C 形带，厚 2 厘米 | 外半径 0.25（y=0.42，碗底）→ 0.279（0.55）→ 0.30（0.69）→ 0.288（顶 0.745）；圆心 z=−0.015。<br>扶手前端 z：0.20（y≤0.48）→ 0.17（0.55）→ 0.095（0.61）。<br>再往上圆弧带张角：±90°（0.66）→ ±72°（0.69）→ ±48°（0.72）→ ±26°（0.745），形成后高前低的斜沿。 |

- 实例 `chair-08`：`position [3.897, 0.086, 11.785]`，`yaw 180`。其他同款椅子只需摆实例。
- 关键尺寸（世界坐标）：
  - 全宽 0.60 米，全深 0.52 米（z 11.58–12.10）；
  - 靠背顶 0.837 米，扶手在中部约 0.72 米，坐面 0.554 米，前沿滚边顶 0.594 米；
  - 地面 0.086 米。
- 建模时的一个技术细节：`loft` 每层的起点取自"顶点重心向 +x 的射线"。
  所以 U/C 带的内边写成密点折线，外边只用少量 ≤30° 圆弧，保证每层重心都落在空腔里、起点都在内壁右侧，各层之间不会拧。
  这一点已逐层核对过。
- 生成轮廓点的脚本：概念验证时的临时脚本（未保留），
  最终参数在同目录的 `p3.json`。脚本只把我定的参数展开成点，没有用任何拟合函数。

## 每轮修改与偏差

偏差用 `compare --object chair-08 --front 180` 测，单位厘米。

| 轮 | 改了什么 | 扫描→模型：均值 / P90 / 3 厘米内 / 1 厘米内 | 模型→扫描：均值 / P90 / 3 厘米内 |
|---|---|---|---|
| 现有算法 | — | 5.53 / 15.90 / 48.0% / 17.9% | 4.77 / 9.36 / 38.3% |
| 1（r1） | 初稿：外壳、内衬、靠背垫、坐垫、座盆、四腿 | 6.13 / 18.37 / 58.8% / 40.1% | 3.72 / 7.74 / 51.3% |
| 2（r2） | 坐垫降到 0.468，加前沿滚边 | 6.05 / 18.35 / 59.0% / 41.6% | 3.69 / 7.67 / 51.4% |
| 3（r3，最终） | 两侧上部外撇（半径随高度加大到 0.30），靠背垫加高到 0.715，中心 x 改为 3.897 | **6.05 / 18.57 / 59.0% / 45.0%** | **3.65 / 7.55 / 51.8%** |

- **均值和 P90 为什么比现有算法差**：差在桌面点上。
  - 漏建块列表里最大的一块是 747 个点，范围 y 0.745–0.843、z<11.86，平均距离 15.9 厘米，全是会议桌桌面和桌沿。
  - 现有算法的靠背顶建到了 0.909 米，比实际高 7 厘米，反倒更"接近"桌面。
  - 其余两块也不是这把椅子：一块是 x≈4.22–4.25 的 chair-09 壳边，另一块是 y 0.13–0.26 的不明低处碎片。
- **去掉桌面后的诊断**：把范围上沿压到 y=0.832（`--box 3.565,0.075,11.558,4.232,0.832,12.13 --fit-margin 0`），
  剩下 1729 个点，几乎都在椅子本身上。
  - 新模型：均值 1.93 / P90 5.15 / 3 厘米内 83.8% / 1 厘米内 62.9%；
  - 现有算法：2.89 / 5.19 / 63.5% / 22.1%。
- **部件偏差**：
  - 外壳贴合最好：部件→扫描均值 2.42，3 厘米内 75%。
  - 四条腿和座盆的部件→扫描偏差大，是因为扫描里没有腿和座底，不是位置错了。

## 结论

- **新模型比现有算法好的地方**：
  - 外壳是闭合的桶形，后高前低，扶手斜沿顺滑下降；
  - 内衬布面和外壳皮面分开上色；
  - 靠背垫后仰，坐垫带前沿滚边；
  - 腿是外撇的锥形腿；
  - 结构对称、规整，可以作同款 8 把椅子的模板。
- **现有算法的问题**：
  - 靠背是一块拧着的、不对称的马蹄形放样，顶面平，高出实际 7 厘米；
  - 腿几乎是直的，间距只有 0.26 米，而地面腿影显示是 0.41 米。
- **不确定的地方**：
  - 前腿位置看不到，是按后腿间距和坐面中心对称推定的；
  - 腿的粗细是按地面腿影估的。
