# 滨海湾草地扫描素材

修剪草坪采用 Grass Ground，滨海中心和滨海步道的种植带采用 Leafy Grass，浮尔顿路分车带采用 Sparse Grass。扫描来自 Poly Haven，按 CC0 分发。草类选择和现场覆盖程度为视觉估计。站点的草坪底色、种植范围和大尺度明暗沿用已有的采样。每组的颜色、法线和粗糙度使用相同取样坐标。

- [Grass Ground](https://polyhaven.com/a/grass_ground)
- [Leafy Grass](https://polyhaven.com/a/leafy_grass)
- [Sparse Grass](https://polyhaven.com/a/sparse_grass)
