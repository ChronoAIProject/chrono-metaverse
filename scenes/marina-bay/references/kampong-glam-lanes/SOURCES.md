# 甘榜格南巷道铺装

按普通地图中有明确地面材质记录的混凝土通道和石铺步道建面。survey.json 保存 OpenStreetMap 路段编号、版本和裁剪后的地面轮廓。宽度依航片估计，路面在地图建筑边缘和机动车道处裁开。颜色样本取自 OneMap 正射影像，按材质中位色归一后用于几米尺度的明暗变化。[OpenStreetMap 数据许可](https://www.openstreetmap.org/copyright) · [OneMap](https://www.onemap.gov.sg/)

混凝土的颜色、法线与粗糙度取自 Concrete Floor 02，颜色归一为暖灰，扫描按约两米平铺。巴索拉街的石铺表面复用仓库已有的 Granite Tile 04，石块尺寸和铺向是视觉估值。两套材质采用 CC0。[Concrete Floor 02](https://polyhaven.com/a/concrete_floor_02) · [Granite Tile 04](https://polyhaven.com/a/granite_tile_04)
